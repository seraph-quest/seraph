# Seraph v2026.7.4 Release Notes

Seraph v2026.7.4 is the July 4, 2026 release line for GPU-hosted VLM chat readiness, fast cockpit metadata, and screenshot-folder reliability.

## Highlights

- Runtime and settings metadata return quickly without inline GPU/VLM health probes.
- Cockpit keeps the last-known local runtime label through transient status failures instead of falling back to stale unknown/default provider text.
- Screenshot analysis scheduling backs off from one-second churn while preserving bounded backlog draining.
- Seraph reports GPU VLM chat readiness through the wrapper `/health/chat` path without exposing secrets.
- Settings and cockpit controls remain usable while proof-grade benchmark and guardian surfaces are loaded explicitly.
- Screenshot-folder ingestion and reports preserve direct-root semantics and current pending-analysis visibility.

## Companion VLM Wrapper

- Companion wrapper release: `vlm-screenshot-server v0.2.0`.
- The wrapper release includes authenticated chat health, OpenAI-compatible streaming chat proxy support, queue status/clear controls, one-GPU priority dispatch, and GPU LAN backend routing.

## Boundaries

- Seraph runtime traffic uses the documented HTTP topology: backend `127.0.0.1:8004` to VLM wrapper `192.168.1.26:8001` to GPU model server `192.168.1.26:8000/v1`.
- SSH remains a GPU administration path only, not a Seraph runtime requirement.
- Fast metadata responses are configuration/status surfaces; live GPU proof belongs to wrapper health endpoints and route-diagnosis receipts.
- This release improves operator capability and reliability but does not claim full parity, broad superiority, or that Hermes/OpenClaw/IronClaw have been exceeded.
