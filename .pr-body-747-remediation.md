## What this changes

Completes the governed local capability boundary for the adopted filesystem and process tools. The authority/approval wrappers now route real bundled callers through a registry-only, redacted, journaled effect host with fail-closed restart recovery and child resource limits.

## Scope

- Adopt filesystem and process tools through the existing authority/approval wrappers and final host hook.
- Bind owner, capability/version, normalized destination, request digest, and approval/fencing data into a stable effect identity.
- Persist bounded `0600` HMAC-sealed digest-only prepared/started/succeeded/failed/uncertain journal records under a cross-process lock; unfinished or unacknowledged effects become uncertain and are never blindly replayed.
- Reject arbitrary constructor handlers, adopted-name custom tools, network destinations, unbounded inputs, and receipt serialization/persistence failures; bind native SWE process and workspace effects to the host with job/fence context.
- Enforce existing workspace/process-group controls plus CPU, address-space, PID, file-output, timeout, and bounded log-read limits.
- Preserve explicit residual limits: full DB-backed multi-process leases and container-grade isolation remain separate work.
