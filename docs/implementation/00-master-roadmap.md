# Historical Seraph Roadmap

**State:** Archived

This page records that Seraph previously used a multi-workstream strategic
roadmap. Its detailed checklists, milestone translations,
and completion receipts are preserved in Git history and the closed
[#475 program](https://github.com/seraph-quest/seraph/issues/475).

The roadmap is not an active queue, accepted target, or operating instruction.
Use the [Project Constitution](./00-project-constitution.md) for product and
architecture decisions, [Development Status](./STATUS.md) for shipped truth,
and Epic [#736](https://github.com/seraph-quest/seraph/issues/736) plus its
Project items for current execution.
