## What this changes

Corrects the Epic #736 health collector so a keyless local receipt reports evidence honestly. Schema v2 labels configuration, static source, external-unverified, and excluded evidence modes; the collector no longer requires a single historical model ID or treats deferred HarnessDev/comparator work as required completion.

- Keep all external provider, GPU/VLM, speech, connector, and comparator checks network-free and clearly unverified.
