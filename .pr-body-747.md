## What this changes

Adds a common local capability execution choke point that performs typed authority checks before effects, serializes duplicate effect identities, and emits redacted execution receipts. The implementation exercises real temporary-file, bounded-process, and denied filesystem/network cases without constructing an external provider client.

## Scope

- `CapabilityExecutionHost` and `CapabilityEffectLedger` behind existing security policy contracts.
- Fail closed on denied/approval-required authority, traversal/symlink/secret paths, untrusted prompt content, private/unsafe network targets, and duplicate in-flight effects.
- Preserve typed output/error metadata and bounded receipt digests without raw output, secrets, or exception text.
- Document the host as a partial adoption seam; existing callers remain governed by their own contracts until migrated.

## Limits

This slice does not claim all capability callers have migrated, absolute security, or provider superiority. Native SWE, browser, process, and extension callers retain their existing local authority paths and need explicit adoption work. An independent Critic/Contrarian review is required before merge; material findings will be recorded on #747.

This preparatory PR intentionally leaves #747 open until the reviewed remediation adopts the host at real callers and closes the durable/isolation gaps above.
