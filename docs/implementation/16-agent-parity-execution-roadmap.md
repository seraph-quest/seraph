# Historical Agent-Parity Execution Program

**State:** Archived

This page is a non-operational record of the parity/proof program formerly
tracked under closed issue
[#475](https://github.com/seraph-quest/seraph/issues/475). It is superseded by
the [Project Constitution](./00-project-constitution.md) and Epic
[#736](https://github.com/seraph-quest/seraph/issues/736).

The historical program compared Seraph with Hermes, OpenClaw, and IronClaw and
produced implementation and evidence batches. Its detailed sequence, prompts,
checklists, and receipts remain available in this file's Git history and the
linked issue/PR history. They are intentionally not reproduced here because
they are obsolete operating instructions.

Current work is defined only by the constitution, ADRs, and tracked Epic #736
issues. Current shipped behavior is recorded in [Development Status](./STATUS.md).
