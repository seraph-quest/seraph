# Seraph v2026.10.7 Release Notes

The October 7 release line brings reviewed Guardian opportunity work and optional
bounded NEAR text answers into the existing operator cockpit.

## Highlights

- OpenRouter text, vision and embedding purposes have separate governed route
  controls and consent while preserving one shared inference lane and accounting.
- Finite Goal policy and immutable public evidence feed cited Guardian
  opportunities in the Inbox. Fixed read-only browser and evidence-report plans
  require an explicit Work preview and acceptance before native execution.
- Explicit Helpful / Not helpful feedback can produce a bounded, provider-free
  preference recommendation. Memory adoption and rollback remain separate
  operator decisions; delivery and task success supply no inferred vote.
- Optional NEAR text questions use the fixed `z-ai/glm-5.3-flash` model through
  standard HTTPS. Setup is disabled by default and requires a separate write-only
  credential, plaintext-egress consent and the existing shared budget ceiling.
- One private question runs as a finite native Work job. A validated private
  answer requires current authority, settled accounting and exact output
  readback; the task requires human Review and records `no_learning`.
  Unknown cost withholds and discards the answer, retains the original liability
  and permits debt reconciliation without resending inference or recovering
  discarded output.
- Package metadata, API version/build ID and cockpit release labels agree on
  `2026.10.7` / `SERAPH_PRIME_v2026.10.7`.

## Boundaries and validation

NEAR receives the question in plaintext. The adapter uses ordinary HTTPS
certificate validation; local private artifacts do not provide provider
confidentiality. No TEE verification, E2EE, live provider availability, live billing
or measured answer-quality result is claimed. Provider-free and intercepted
receipts validate local authority, accounting, native lifecycle and readback.

Automatic CI honors the operator's retirement of harness evaluation campaigns.
The whole `test_eval_harness.py` module and the exact reviewed indirect campaign
consumers are unrun, not passed. Original sources and assertions remain intact;
the remaining configured docs, frontend and ten backend shard checks are release
gates. This release does not represent the retired coverage as tested.
