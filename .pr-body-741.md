## What this changes

Completes the synthetic operator setup path for the local/LAN cockpit. The UI now gates protected startup on the existing server-side session, offers actionable keyless credential provisioning, supports login/refresh/logout recovery, and sends credentialed cross-port requests. Protected runtime/settings reads remain provider-free and redact credentials. Startup failure handling stays observable when durable recovery cannot initialize.

## Scope

- Reuse the existing PBKDF2 operator credential and HttpOnly session cookie.
- Add first-run/setup, login, expiry/revocation recovery, and WebSocket auth-close handling.
- Keep OpenRouter configuration optional; saving configuration does not issue a request or claim readiness.
- Document local HTTP/auth boundaries and the unverified provider state.
