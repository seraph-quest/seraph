# Optional deliberate selected-text companion

The Seraph Mac/Linux CPU core works without this adapter. This first adapter
supports ordinary top-frame HTML in Chromium MV3. It does not capture native
regions, screenshots, clipboard, editable/forms, shadow DOM, PDF, incognito or
restricted schemes. Site-controlled DOM can conceal sensitive ordinary prose;
the operator must review the source and remove secrets. A DOM/MAC digest is
not proof of authorship, human intent or a trusted publisher.

1. Review manifest permissions: activeTab, scripting, contextMenus, trusted
   session storage, and exactly one core host. No broad host or background reader.
   Load this directory unpacked using Chrome's extension settings for the
   default `http://127.0.0.1:8004` core. For another reviewed core, materialize a
   fixed profile with `python3 build.py --core-origin <exact-origin> --output
   <new-directory>`. HTTPS is required except same-host HTTP loopback. This
   command only copies the reviewed local adapter; it installs nothing.
2. Under Seraph Settings → Native, inspect the existing installed optional
   device adapter and explicitly pair or rotate it. Enter its one-time locator
   and credential in the trusted companion configuration; no page script gets
   them. Legacy unowned credentials require deliberate rotation or re-pairing.
3. Select ordinary text and invoke the extension action, selection context menu,
   or its Chrome shortcut. Preview stays in memory, expires after five minutes
   and permits deletion-only redaction. A closed/reloaded preview loses the raw
   draft. Source navigation fails closed. No network happens during capture.
4. In the current owned Task inspector, explicitly publish its current finite
   Goal target for at most 120 seconds. Review source/text in the companion and
   request exact approval. This sends signed metadata only and admits one paused
   native job. Approve its exact source, digest and bytes in that Task inspector.
5. Check the original ticket once, then explicitly send matching signed bytes.
   The local native job writes and reads back encrypted private D1 text. Read it
   through the current Task inspector while the original target remains valid.
   Expired permission denies reads and new use. No automatic analysis or learning
   happens; attachments never become executable inputs or canonical memory.
6. Discard in the Task inspector: tombstone first, then bounded capture-owned
   file cleanup. Failed cleanup stays visible and charged; explicitly retry the
   same original discard identity. Discard does not delete shared pairing secrets
   or the owner Vault key. Retained encrypted audits are not physical erasure.

32 KiB UTF8 / capture, 48 KiB envelope, 4096 traversed DOM nodes, 15-second native
runtime, one attempt and one outstanding capture per owner; 64 charged captures
and 2 MiB retained/reserved per owner. There is no polling, automatic send/retry,
model/provider contact or screenshot observation. Lost responses require reading
the original canonical Task receipt; replay cannot resurrect a tombstone.

The fixed public manifest key makes the extension address stable; it grants no
publisher trust. Only four paired POST paths accept that exact present extension
Origin, current owner bearer and domain-separated body MAC. Cookies are rejected.
Global CORS, existing cookie endpoints, nodes ingress and OPTIONS are unchanged.
